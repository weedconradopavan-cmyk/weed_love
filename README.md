# Portfólio profissional

Site estático feito com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — visual e responsividade
- `script.js` — conteúdo e interações
- `assets/favicon.svg` — favicon

## Como editar

Abra `script.js` e altere somente o objeto `portfolioData` no início do arquivo.

Ali você pode trocar:
- nome
- cargo
- biografia
- links
- experiências
- habilidades
- cursos
- formação
- projetos
- trajetória
- objetivos

Depois, publique novamente no GitHub Pages.
